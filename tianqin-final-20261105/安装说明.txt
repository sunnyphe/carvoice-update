天琴 DeepSeek 改造版安装说明
==============================

架构
----
保留天琴原有：你好小蜜唤醒、ASR、车控、界面、TTS、回声消除。
仅替换开放问题的回答：原天琴回答会被截断，改由 DeepSeek 生成，再交给天琴原 TTS 播报。
车控指令仍走原天琴流程，不交给 DeepSeek。

文件
----
1-天琴语音服务-daemon.apk
2-天琴语音界面-view.apk
3-Tianqin-DeepSeek-最终桥接.apk

全新安装顺序
------------
1. 安装 1-天琴语音服务-daemon.apk
2. 安装 2-天琴语音界面-view.apk
3. 安装 3-Tianqin-DeepSeek-最终桥接.apk
4. 打开“语音”，按系统提示允许悬浮窗/显示在其他应用上层。
5. 保持联网，说“你好，小蜜，为什么天空是蓝色的”，应听到 DeepSeek 风格的完整回答。
6. 说“打开空调”或“关闭车窗”，应继续由原天琴执行和播报。

如果车机已装过天琴三件套
------------------------
通常只需覆盖安装“3-Tianqin-DeepSeek-最终桥接.apk”。
如果提示“签名不一致 / 应用未安装”，先卸载原 com.dofun.bridge，再安装第 3 个 APK；
daemon 和 view 不需要卸载。

注意
----
- DeepSeek API Key 已内置，不需要在车机输入。
- 手机没有车控硬件，因此手机测试“打开空调”时可能只听到天琴确认音，不能真实控制空调；车机上由原天琴车控链路执行。
- 后续升级只需替换第 3 个桥接 APK。
