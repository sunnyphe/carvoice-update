天琴 DeepSeek 改造版安装说明（2026-11-06 语音修复版）
====================================================

架构
----
保留天琴原有：你好小蜜唤醒、ASR、车控、界面、回声消除和 TTS 声线。
开放问题由 DeepSeek 生成，再使用天琴原 TTS 生成的 PCM 音频播放。
车控指令仍走原天琴流程，不交给 DeepSeek。

本版修复
--------
- DeepSeek 回答现在有语音，不再只显示文字。
- 识别到开放问题后立即关闭原会话，显示“正在思考…”。
- 原助手的“没有听清，请重说”“抱歉，没有找到哦”等兜底回答不会抢答。
- DeepSeek 长回答使用独立文字浮层完整显示，不再被原助手文字截断。
- 天琴原音频生成完成后，先停止重复播放，再由桥接程序完整播放一次。

文件
----
1-天琴语音服务-daemon.apk
2-天琴语音界面-view.apk
3-Tianqin-DeepSeek-最终桥接.apk

全新安装顺序
------------
1. 安装 1-天琴语音服务-daemon.apk
2. 安装 2-天琴语音界面-view.apk
3. 安装 3-Tianqin-DeepSeek-最终桥接.apk
4. 打开“语音”，允许悬浮窗/显示在其他应用上层。
5. 保持联网，说“你好，小蜜，为什么天空是蓝色的”。
6. 应显示“正在思考…”，随后显示并朗读 DeepSeek 完整回答。
7. 说“打开空调”等车控指令，应继续由原天琴执行。

如果车机已装过天琴三件套
------------------------
通常只覆盖安装“3-Tianqin-DeepSeek-最终桥接.apk”。
如果提示签名不一致，先卸载原 com.dofun.bridge，再安装第 3 个 APK；
daemon 和 view 不需要卸载。

注意
----
- DeepSeek API Key 已内置，不需要在车机输入。
- 手机没有车控硬件，因此手机上的“打开空调”只能验证分流和确认播报，不能真实控制空调。
- 后续升级只需替换第 3 个桥接 APK。
