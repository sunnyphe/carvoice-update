天琴 DeepSeek 改造版安装说明（2026-11-06 统一路由版）
====================================================

当前原则
--------
沿用天琴原流程：
用户说话 → 天琴原 ASR → DeepSeek 生成回答 → 天琴原文字展示 → 天琴原 TTS 播报。

所有识别文本统一交给 DeepSeek，不再判断车控指令，不做分流。
不使用第三方回答浮层，不改变天琴原对话界面。

实现链路
--------
1. 天琴完成原方式语音识别。
2. 桥接层终止原天琴后台请求。
3. 将 ASR 文本提交 DeepSeek。
4. DeepSeek 返回后重新进入天琴原会话入口。
5. 通过天琴原 speak 通道发布文字并生成原 TTS 音频。
6. 原界面逐步展示回答，原 TTS 声线播放回答。

文件
----
1-天琴语音服务-daemon.apk
2-天琴语音界面-view.apk
3-Tianqin-DeepSeek-最终桥接.apk

全新安装顺序
------------
1. 安装 1-天琴语音服务-daemon.apk
2. 安装 2-天琴语音界面-view.apk
3. 安装 3-Tianqin-DeepSeek-最终桥接.apk
4. 打开“语音”，允许悬浮窗/显示在其他应用上层。
5. 保持联网后直接使用原方式唤醒和提问。

如果车机已装过天琴三件套
------------------------
通常只覆盖安装“3-Tianqin-DeepSeek-最终桥接.apk”。
如果提示签名不一致，先卸载原 com.dofun.bridge，再安装第 3 个 APK；
daemon 和 view 不需要卸载。

注意
----
- DeepSeek API Key 已内置，不需要在车机输入。
- 所有问题均由 DeepSeek 回答，包括“打开空调”等原车控指令。
- 后续升级只需替换第 3 个桥接 APK。
