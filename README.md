# Car Voice Update Channel

Public binary-only update channel for the private source repository:

https://github.com/sunnyphe/carvoice-assistant

This repository intentionally contains no source code, API keys, signing keys, or GitHub tokens.

- `update.json`: version manifest with SHA-256
- `CarVoiceAssistant-car.apk`: final car APK
- `index.html`: human-readable update page
